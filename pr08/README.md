
# ПР-8. Взаимоблокировки (вариант B)

## Цель
Воспроизвести deadlock, реализовать алгоритм банкира и детектор циклов
в графе ожидания.

## Задание 1. Алгоритм банкира
```
python3 banker.py bank1.txt
python3 banker.py bank2.txt
```

Ожидаемый вывод:

```
bank1: SAFE, последовательность: P1 P3 P4 P0 P2
bank2: UNSAFE
```

Запрос из задания 4 (Silberschatz §8.6.3): в bank1 ввести `P1 1 0 2`:

```
request P1 [1, 0, 2]: GRANT (состояние осталось безопасным)
```

Проверка запроса: сначала выделяем «в пробном режиме», запускаем проверку
безопасности; если состояние небезопасно — откат выделения и отказ.

## Задание 2. Детектор по журналу событий
```
python3 dd.py deadlock.log
```

Вывод:

```
<ВСТАВИТЬ ВЫВОД — будет цикл P1 -> P2 -> P1>
```

Строим граф ожидания (не граф распределения!): ребро A→B = A ждёт ресурс,
который держит B. Цикл ищем DFS по трём цветам.

## Задание 3. TrackedLock
```
python3 tracked_lock.py
```

Вывод:

```
<ВСТАВИТЬ ВЫВОД>
```

Перед каждым захватом обёртка смотрит, кто держит блокировку, добавляет ребро
«я жду его» и проверяет, не замкнётся ли цикл. Если да — DeadlockError вместо
вечного ожидания.

## Задание 4. Обедающие философы
```
python3 philosophers.py naive     # зависнет (не ждём дольше 5с)
python3 philosophers.py ordered   # нумерация вилок
python3 philosophers.py waiter    # официант: семафор N-1
```

Выводы:

```
<ВСТАВИТЬ ВЫВОД трёх режимов>
```

Статистика «сколько раз поел каждый» при ordered/waiter близка к равномерной;
naive зависает сразу после того, как все возьмут левую вилку (удержание
и ожидание + круговое ожидание). Нарушенные условия: нет упорядочивания
ресурсов (исправление 1), нет ограничения ожидания (исправление 2).

## Выводы
Deadlock требует 4 условий; ломаем одно из них — упорядочиванием захвата
или ограничением ожидания. Банкир предотвращает (запрос откатывается),
детектор обнаруживает по графу ожидания.
