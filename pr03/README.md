## Задание 3. Зомби и сирота

Терминал 1:
```
python3 zombie.py &
ps -eo pid,ppid,stat,cmd | grep -E 'Z|zombie'
```

Вывод ps (строка со статусом Z):

```
<ВСТАВИТЬ>
```

Зомби — завершившийся процесс, чей родитель ещё не вызвал wait: запись в таблице
процессов (PID, код возврата) остаётся, пока родитель не заберёт статус.
После завершения родителя сирота усыновляется init (PID 1) или subreaper —
в WSL/Ubuntu смотреть PPID после смерти родителя:

```
python3 orphan.py &
# через секунду:
ps -o pid,ppid,stat,cmd -p <PID ребёнка из вывода>
```

Вывод:

```
<ВСТАВИТЬ: у сироты PPID стал 1 (init)>
```

## Задание 4. Ленивое копирование (COW)
```
python3 cow.py
```

Вывод:

```
<ВСТАВИТЬ ВЫВОД>
```

Сразу после fork RSS ребёнка почти не растёт — страницы общие (COW).
Как только ребёнок начинает писать в список, ядро копирует затронутые страницы,
и RSS удваивается. Родитель при этом не меняется.
